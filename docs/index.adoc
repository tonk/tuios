TUIOS (Terminal UI Operating System) is a terminal-based window manager with a vim-like modal interface, workspaces, tiling, persistent sessions, and SSH and web access.
This index lists every document in this directory, grouped by topic.
For an overview of the project and how to install it, see the link:../README.md[README].

All documents are also bundled as chapters of one book, xref:tuios-book.adoc#doc-tuios-book[tuios-book.adoc]; `make docs-pdf` builds it as `tuios-book.pdf`.
