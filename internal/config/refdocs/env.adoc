The `+[env]+` table lists extra environment variables that tuios exports into every shell it spawns, in local windows and in daemon-backed sessions alike.
They are added on top of the environment tuios itself inherited and after the variables tuios sets itself (such as `TERM`, `COLORTERM` and `+TUIOS_WINDOW_ID+`), so an entry here overrides an inherited variable of the same name, and even one of tuios's own.
Values are taken literally: there is no expansion of `$HOME`, `~` or other variables, and every value must be a quoted TOML string.

The table is read again each time a window is created, so an edit applies to the next new window without restarting tuios; shells that are already running keep their environment.
For daemon-backed sessions the daemon reads its own copy of the configuration file.
A key that is not a conventional variable name (letters, digits and underscores, not starting with a digit) produces a config warning but is still exported as written.
Hook commands do not receive these variables; they get the environment of tuios itself plus their own `+TUIOS_*+` variables.

[source,toml]
----
[env]
EDITOR = "nvim"
PAGER = "less -R"
MY_PROJECT_ROOT = "/home/me/src/project"
----
